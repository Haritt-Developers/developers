A day planner that records what you actually did.

Most planners only hold what you meant to do. HV Reset times each task as you do it, shows where the day really went, and makes it easy to start again after a bad day.

01 · The problem

One late start, and the whole plan is gone.

Missed your plan? Wasted a day? Lost your routine?

The first line HV Reset shows a new visitor

A to-do list cannot tell the difference between a task you planned and a task you did. People end the day unsure where the time went, and one late start quietly ruins the rest of the plan.

We wanted three things: see only the task in front of you, record real time, not planned time, and make restarting take one tap.

03 · Product decisions

The whole idea, in the four screens a new user sees.

1 of 4A plan is a list of tasks with times. Start from a ready plan, not a blank page.

2 of 4While you work, you see one task and the time left. Nothing else competes for attention.

3 of 4Every task you start is timed, so the dashboard shows real time, not planned time.

4 of 4A score built only from what you really did, with patterns you can act on.

Rules we gave ourselves

  • Planned time is never counted as work.Only timed work counts.
  • Missing data says “not tracked”.It never shows as zero.
  • Comparisons wait for enough data.The score appears after about three finished tasks and two planned days.
  • Running late moves the day, not the guilt.One question shifts the rest of today.
04 · The product

Plan a day in four steps.

In plain wordsTap through the steps to see the real app.

When a task starts late

One question instead of a broken plan.

Start a task 5 minutes or more late and HV Reset asks once whether to move the rest of today by the same time. Yes shifts every later task. No keeps the times and the next task says “as planned”.

Adding a task

Now, today, tomorrow or a date.

A small sheet with the time and length already filled in, so adding a task takes seconds.

05 · How it is built

One app for the browser and Android, saved to your own account.

In plain wordsHV Reset opens in any browser and also runs as an Android app. Anyone can try it without an account. Signing in with Google saves the plan, so phone and laptop stay in step.

  • HTML5App interface
  • JavaScriptApp logic, no framework
  • FirebaseGoogle sign-in and saved plans
  • Gemini APIHV AI planning
  • CapacitorAndroid app shell
  • AndroidClosed testing
  • GitHub ActionsAndroid builds
  • GitHub PagesWeb hosting
Technical detailsData, security and the Android build+
  • Data model. Each start, pause, resume and finish is stored as a timer session for that day. Focus ratings, interruptions, moves and skips are kept separately, and each day keeps a copy of its own plan, so editing the plan later never rewrites history.
  • Security. Firestore rules let a signed-in user read and write only their own users/{uid}/ space. Guests' changes stay in that browser tab until they sign in.
  • Sync. The browser keeps a working copy per account. Phone and laptop stay in step within about 15 seconds. Signing out removes the copy from that browser.
  • Shared account. HV Reset and HV Hunt live on the same site, so one Google sign-in works for both.
  • Android. A Capacitor shell loads the same web code and adds a native bridge for exact-time reminders and native Google sign-in. GitHub Actions builds a debug APK on every push, and a signed app bundle for Play on request.

09 · Learnings and what is next

What building it taught us.

Honest numbers need rules.

A dashboard built on planned time can look great and mean nothing. Every number in HV Reset comes from timed work, and missing data says so.

Scores invite shortcuts.

If ticking “done” early earns full credit, people tick early. Credit now follows the time actually worked and how focused it was.

Let people try before signing up.

Guests can use everything. HV Reset asks them to sign in only when there is something worth saving.
