01 · The need

A parent brand that does not compete with its children.

Two ventures, two audiences, one family.

The challenge, in one line

Haritt Developers serves businesses. HV Verse serves students and job seekers. The group mark had to work for both, stay recognisable at 16 pixels, and let each venture keep its own look.

The old marks were round badges with text inside them, hard to read at small sizes and different from each other. We replaced them with one symbol, used in a different colour by each brand.

04 · The website

A short film instead of a long page.

In plain wordsThe home page plays like a short film. One scroll moves to the next scene. Thousands of dots form the Haritt flame, then spell out what Haritt does.

Ventures page

Each venture in its own colours.

The group site stays cream and crimson. Each venture gets a full-screen section in its own palette, so visitors see how separate the brands are.

05 · How it is built

A static site with a 3D layer.

In plain wordsThe site is a set of fast, ready-made pages. Only the dot animation runs live in the browser.

  • Next.jsPages, static export
  • ReactInterface
  • TypeScriptCode
  • Three.jsDot animation
  • GSAPScene timing
  • Tailwind CSSStyling
  • GitHub PagesHosting
  • CloudflareDomain and DNS
Technical detailsRendering and motion+
  • Static export. Next.js builds every page ahead of time, so pages load as plain files. Moving between pages does not reload the site.
  • Dots. Rendered with Three.js through React Three Fiber. Shapes are sampled from the real logo and from text, and the dots move between them.
  • Scenes. One scroll gesture moves one scene. Wheel, touch and keys are handled the same way.
  • Phones. Phones use an even hexagonal grid of dots instead of random ones, for a cleaner shape on small screens.
06 · Learnings

What changed after we saw it on real screens.

Hover can break the idea.

Dots that moved away from the cursor looked clever, but they broke the flame. We removed the effect.

Phones need their own design.

Random dots looked fuzzy on a small screen. An even grid made the shapes sharp without changing desktop.

Less on screen reads as premium.

The first hero had a headline, buttons and extra text. Taking most of it away made the film work.
